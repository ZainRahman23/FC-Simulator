Response functions

h = finite nonnegative button hold in milliseconds
h < 80: no registered shot (harness hypothesis)
q = clamp((h − 80) / 520, 0, 1)
f(q) = 0.40 + 0.60 × [1 − (1 − q)²]
θ(q) = 1.5° + 10.5° × q³ × (4 − 3q)
C = unchanged clean BALL-SHOT-1.2 Laces capability
speed = C × f(q)
forward = speed × cos θ
vertical = speed × sin θ
spin = [0, 0, −4] rad/s

Valid 80 ms input has q = 0 but still requests 40% of capability. All players share the same q, speed fraction and angle at a given hold. A 50-SP shot remains 31.28% slower than 90 SP at every hold. The 600 and 800 ms launches, spin, every native replay frame and physical event match exactly at all five ratings.

Speed rises quickly and its slope fades toward the cap. Elevation rises later using a quartic that also tapers to zero slope at full charge; this prevents forward speed from declining near the cap. The elevation rate peaks at q = ⅔, then eases into full elevation. The response has no ground/air threshold. Speed and elevation are separate functions so a later trajectory modifier can suppress lift without changing the capability request; none is implemented here.

Useful window and full-charge timing

200–450 ms is the proposed normal useful window, with 250–400 ms the main working range. At 250 / 350 / 450 ms, speed reaches 72.82% / 86.13% / 95.01% of capability. At 500 ms it reaches 97.78%. These values provide a broad middle range for visual review.

600 ms is appropriate as the initial full-power hypothesis. Nearly all speed is available before that; late hold mostly raises trajectory.
