# gk_anim — Goalkeeper Animation V1 tooling

All tools read the simulation; none writes it. Puppeteer scripts need `PUPPETEER_NODE_MODULES` pointing at a `node_modules` containing `puppeteer-core`, the mirror static server on port 8126 (repo root symlinked), and pass an explicit `--udd` / `userDataDir`.

| tool | purpose |
|---|---|
| `gk_measure_sprites.py <dir> <out.json> [--sheet out.png]` | anchors for an 8-direction state (bbox, foot row, head, gloves, feet, pelvis/shoulder rows) |
| `gk_measure_clip.py <clip_dir> <out.json> [--sheet out.png]` | per-frame anchors of an authored clip (gloves/lead glove/head/planted feet, baked displacement, airborne px) |
| `gk_build_manifest.py` | declarative CLIP_TABLE → measures every clip → writes `assets/visual_v1/goalkeeper/GK_ANIM_V1.json` (tracked, generated: rerun after adding art) |
| `gk_anim_gate.js --url … --anim on|off --out gate.json` + `gk_anim_gate_compare.py a.json b.json …` | simulation-neutrality gate: per-scenario trace hashes with the animation drawn every tick vs disabled vs a frozen page |
| `gk_measure_pose.py <dir> <out.json> [--sheet]` | anchors for an 8-rotation POSE state (gloves anywhere, lead glove, body centre) — used by the runtime's screen-axis matching |
| `gk_coord_audit.py <basis.json> <records.json> <anchors_dir> <manifest> <out>` | world→screen movement basis table, V1 simulated-vs-drawn displacement decomposition, axis diagrams (S / SW / W facings) |
| `gk_anim_audit.py <strips_dir> <manifest>` | Phase-29 consistency audit from an `anim_strips.js` capture set (visual error, flags, facing continuity, root continuity, early contact pose, family vs contact surface) |

Review page: `sandbox/visual/gk_anim_review.html` (+ `gk_anim_review.js`) — physics replay of synthetic keeper-frame arrivals and art playback of clips / candidate poses / diagnostics.

Review harnesses kept with the review artifacts (scratch, not tracked): `anim_strips.js` (deterministic per-scenario capture strips + records), `strip_sheet.py`, `pose_sheet.js` (8-direction coverage sheet through the runtime's own resolver), `perf_probe.js`, `ik_debug.js`.

Tracked vs generated: `GK_BASE_V1.json` (hand-maintained record), `anchors/*.json` and `GK_ANIM_V1.json` (generated by the tools above, tracked so the page works without running Python), review sheets (generated, kept under `review_artifacts/`, never committed).

## V1.2 — camera-space save poses (`v1_2/`)

Two save directions only (SAVE_GOAL_LEFT = up the screen / far post, SAVE_GOAL_RIGHT = down the screen / near post), authored on real renderer plates.
Serve the repo root on port 8126 and set `PUPPETEER_NODE_MODULES` to a folder containing `puppeteer-core`.

| tool | purpose |
|---|---|
| `plates.js <out>` | Phase 1 proof at the live camera, 1:1 authoring plate (sprite scale 1.0) and per-pose generation plates with the ball at the simulation's committed target |
| `annotate.py` | annotates the proof / references (goal line, save arrows, depth, vertical) |
| `extract_pose.py <input_plate> <edited_plate> <crop_meta.json> <out_prefix>` | extracts the keeper from a PixelLab edit (SET-palette classification, ball removal, anchors: root / gloves / lead glove / head) |
| `build_manifest.py <gen_out> <gen_small> <dest>` | assembles `GK_SAVE_POSES_CANDIDATES.json` + pose PNGs/anchors (all `candidate: true`) |
| `poses_sheet.js <out>` / `poses_sheet.py` | drives the review page (SAVE SIDE, heights, laterals, RAW / IK) and builds the 8-pose review sheet on the gameplay camera |
| `matrix2_run.js <out> [speed]` / `matrix2_sheet.py` | two-direction decision matrix (GOAL_LEFT / GOAL_RIGHT × LOW/MID/HIGH/TOP × SMALL/MED/LARGE) |

`gk_anim_gate.js` now accepts a URL with a query string (`match.html?savePoses=1` loads the candidate manifest on the playtest page).
