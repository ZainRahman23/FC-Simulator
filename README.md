# Touchline

A football coaching game: build a playing system and squad, train their combinations, prepare Tactic Cards, then watch and coach the match in Broadcast or Tactical view.

Start with the [screenshot walkthrough and setup instructions](README_TOUCHLINE.md).

- [Core Loop v2 design](docs/CORE_LOOP_V2_SPEC.md)
- [Verification results](docs/V2_VERIFICATION.md)
- [Simulation and balance report](tools/balance/report.md)
- [Development chronicle and project principles](docs/TOUCHLINE_DEVELOPMENT_CHRONICLE.md)

The Python engine resolves the football. The manager layer supplies tactics, roles, training and match-scoped modifiers; both visual views present the same authoritative match.
