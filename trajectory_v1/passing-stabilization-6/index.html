Difficulty formula

Control demand C = ideal travel time × (launch speed − 2.5 m/s)
Through difficulty D = D20 × C / C20 + existing redirection + runner-motion terms
Base rating response g = ((99 − effectiveAccuracy) / 89)^1.2
Directional spread = 5.5 × 1.2 × 1.25 × g × D
Weight spread      = 0.25 × 1.35 × 1.25 × g × D

This measures how much initial pace the delivery must shed, for how long that control must remain effective. The 20 m reference retains the easy-pass scale. There is no extra distance multiplier applied to the final error.

The existing bounded draw character and tiny elite floors are retained. Directional error projects naturally across the requested depth; weight error is expressed in metres using the reference control distance. A bounded pre-contact solve chooses pace/backspin that physically produces that error. It prevents a change in turf response or a speed cap from shrinking the requested miss. The ball receives one launch; nothing steers it afterward.

MEASURED BOTTLENECK · NO CROSS RETUNE

Less work for the same physical cross.

  1. Replace generic deep-copy snapshots with exact copies of the ball’s known state. Solver-only probes copy only time and position. Forces, contacts, substeps and orientation integration are unchanged.
  2. Stop a failed solve when a freshly computed Jacobian cannot improve the candidate. Rebuilding the identical Jacobian at the identical point could not produce a different answer.
  3. Retain the ideal-based starting estimate: ideal vertical velocity, depth-adjusted horizontal velocity and intended direction plus sampled offset. Retain the existing in-solve Jacobian updates.

The original symmetric feasibility fallback remains: test both opposed errors; if either is infeasible, apply the same contraction to both. It is deterministic, records its scale, and preserves a centred distribution. Failed numerical solves cannot loop indefinitely. No cache is required.
