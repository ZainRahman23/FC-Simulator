Movement model

Corrections up to 30° keep the existing smooth running controller. Larger corrections reduce entry speed continuously with angle, brake along the incoming direction, hold a short support step while the body turns, then redirect and accelerate toward the updated target. Ordinary target refinements update the direction without restarting an ongoing plant. The player resumes the original running controller once aligned and back at pace.

A fixed neutral/high reference profile controls the redirect: braking 18 m/s², bounded redirect acceleration 22 m/s², push acceleration 9 m/s², maximum body turn rate 720°/s and angular acceleration 5,400°/s². The support step ranges from 35–90 ms and waits for body alignment within 20° before push-off. These are authored reference capabilities, not rigid-body football constraints.

The navigator accepts a separate movement-capability profile so Agility can later affect how quickly the redirect happens. No new Agility mapping is introduced. Existing Agility-dependent smooth running and RECEIVE behavior remain as before, and each runner’s sprint-speed limit is preserved.

Preserved prediction: the existing meeting-point and feasibility solvers still use their original RUN forecast. This change replaces the executed approach path only. The 150 ms replans feed the runner’s new actual state back into those unchanged solvers; their future outputs and receive timings can therefore differ. Aligning the forecast with the new cut controller is outside this change.
