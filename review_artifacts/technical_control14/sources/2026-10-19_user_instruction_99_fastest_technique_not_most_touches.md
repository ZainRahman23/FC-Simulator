# Owner instruction — 2026-10-19 (after TECHNICAL-CONTROL-1.3 was presented), verbatim

Yes. This is an important correction to the Dribbling 99 philosophy.
We've overcorrected toward “elite = constantly touching the ball.” That's wrong. Elite Dribbling should mean the player can execute the required manipulation faster and with fewer unnecessary setup touches.
So for a 99 dribbler, a 90–150° change shouldn't necessarily be:
touch → adjustment touch → adjustment touch → cut → recovery touch
when the geometry permits:
one explosive Ronaldo-chop/through-stance contact → body turns → exit.
The ball can remain close because the single technical action is excellent, not because the player taps it five times.
Send Claude this:
IMPORTANT DRIBBLING CORRECTION — 99 = FASTEST TECHNIQUE, NOT MOST TOUCHES
Before continuing the current cleanup, correct an important issue visible in the latest 99-rated dribbling.
There are far too many touches at Dribbling 99.
We have accidentally interpreted:
high Dribbling
→ maximum touch frequency

too literally.
That is NOT the intended model.
The correct principle is:
Dribbling determines how quickly and efficiently a player can execute the appropriate technical action.

A 99 dribbler should often need fewer touches because they can perform a difficult manipulation immediately.

Remove patterns where an elite player unnecessarily performs:
touch

→ correction

→ cut
→ recovery touch

body turns ~120° left

Do NOT treat those exact angles as locked.
The important thing is the action structure.
At:
Dribbling 99
Ball Control 99
Agility 99

It should not require three preparation touches first.
4. ONE CONTACT CAN SOLVE A BIG DIRECTION CHANGE

ONE chop contact

Separate:

BALL CONTACT COUNT

A complicated body action can contain one authoritative ball touch.

→ cut

immediate cut
