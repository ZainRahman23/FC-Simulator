# 2. CRITICAL AUDIT FINDING — FIX THIS FIRST

The Astra audit found that Stage 3's existing limb-strike channel is physically inconsistent.

The current failure is approximately:

1. an animated limb moves quickly;
2. Stage 3 computes an impulse from that animated limb speed;
3. that impulse is transferred into the bodies;
4. but the limb itself continues on its authored trajectory without losing the corresponding momentum.

Therefore animation can effectively create momentum/energy.

The audit found that limb strikes supplied approximately **94% of Stage 3's matrix impact impulse**.

This must not survive Stage 3B.

## Mandatory replacement rule

For every limb contact resolved by Stage 3B:

**Stage 3B REPLACES Stage 3's existing animated-speed limb-strike impulse path.**

It must NOT supplement it.

There must be exactly one source of momentum from that limb interaction.

Conceptually:

> momentum actually removed from / redirected out of the contacting limb  
> → physically allowable coupled momentum to the player's body/opponent  
> → Stage 3 balance response

NOT:

> animated limb speed  
> → free body impulse  
> while animation continues unchanged.

Instrument this explicitly so the accounting can prove it.

# 7. LIMB MOMENTUM ACCOUNTING

This is the heart of the pass.

For a swinging limb contact, determine the limb's physical contact-point velocity.

Resolve the component that cannot continue because of the opponent.

If the foot slides tangentially, preserve the allowable tangential component.

If the swing is redirected, calculate the change in limb momentum.

If it stops, calculate the momentum actually lost.

Only that physically accounted change may feed the coupled body response.

In simplified form:

**Δp_limb = p_after − p_before**

and body/opponent response must be derived from the corresponding physically available reaction, subject to support/ground constraints.

Do not blindly use the authored limb's absolute animation speed as an impulse generator.

The authored trajectory may therefore need to be locally constrained after genuine limb contact.

That is allowed in Stage 3B.

But the constraint must be:

- continuous;
- anatomically plausible;
- bounded;
- attributable to contact;
- deterministic;
- auditable.

Once contact ends, do not snap the limb back onto the original authored curve.

Reconcile smoothly.
