Stop condition B: an architectural decision is needed. S2, the physiological substrate, qualified 18 / 18. S2 + P2, S2 plus continuous delayed postural control, failed 10 / 14. It stands for 60 s, starts cleanly, is provably causal, recovers forward and backward pushes and loses balance to large pushes. It fails lateral recovery, human-matched recovery and the human no-step thresholds. The labelled successor P2b restored physiological torque dynamics and became unstable before any push.     Why PPR-3 stops: the P2b exploration

    Diagnosis of P2's failures: (1) its torque develops faster than human torque, because the explicit EMG → torque filter had to be removed in design to stabilise the loop; (2) it has no COM acceleration feedback, and the lateral four-bar mode (1.70 × mg/h) is underdamped behind a 100 ms delay. P2b restored the physiological torque path and added acceleration feedback, with three literature variants. Undisturbed and noise-free, all three diverge from the entry. Battery pushes were not run on them. This controller class (independent delayed PID loops through a static Jacobian transpose) is stable on this body only while its torque is superhuman.

    The decision needed (yours)

    1. Where do muscle contraction (EMG → force) dynamics belong? (a) Recommended: in the V2 body spec, as an actuator stage, so no controller can produce superhuman torque development. (b) In P2, which leaves V2 unchanged.
    2. Which controller class does P2 become? (a) Recommended: a model-based delayed multi-joint controller: delayed multisensory state estimation with an internal-model predictor bridging the delay, and coordinated output on the sway modes (ankle / hip / four-bar). It is still causal. (b) Independent PID loops plus acceleration feedback, which is P2's class and is shown unstable here once torque is physiological.

    Either choice is re-qualified on the same frozen S2 + P2 battery. S2 does not change, except that option 1(a) adds an actuator stage, which re-qualifies S2 on its battery.

    Spec recommendation (nothing changed): adopt C (Maxwell strain arms + bidirectional short-range-stiffness cap; body), T (ready-stance tone; neural / feed-forward setting) and A2 (minimum-effort rest statics; feed-forward law). B is optional, through V2's existing neutral-zone term. For P, adopt the architecture but not the current controller.
